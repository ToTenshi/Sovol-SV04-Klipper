# Repository structure

| Path | Contents |
|------|----------|
| `config/Sv04-works-with origin-klipper/` | **Default.** Config for original Klipper (MainsailOS) |
| `config/SV04-with-display/` | Config for the fork `Bully85/klipper` with the original DGUS display (`t5uid1.cfg`) |
| `config/*/sv04_tools.cfg` | `SV04_MENU`, calibration wizards, filament, helpers ([offsets](offsets.md)) |
| `config/*/input_shaper.cfg` | Input shaper preset + runtime logic, always included ([input-shaper](input-shaper.md)) |
| `config/*/adxl345.cfg` | Optional ADXL345 + `SHAPER_CALIBRATE_SV04` (include commented out) |
| `config/*/variables.cfg` | Template for `[save_variables]`: T1 offsets, shaper values. **The user's copy is never overwritten.** |
| `install/sv04-pi-setup.sh` | Setup/update on the Pi ([installation](installation.md)) |
| `install/install-slicer-profiles.sh` | Slicer installer for Linux + macOS |
| `install/install-slicer-profiles.ps1` + `…-windows.cmd` | Slicer installer for Windows |
| `Bambu Studio Profile/` | Bambu Studio user presets, generated by `tools/build_profiles.py` ([slicers](slicers.md)) |
| `Cura Profile/` | Cura definitions/extruders, `MeshPrintSize.py` (replaces `%MINX%` etc.) |
| `Prusaslicer Profile/` | PrusaSlicer config bundle + bed model |
| `Firmware bin/firmware.bin` | Firmware built from the fork (v0.11.0-261), only for the display variant |
| `tools/check_klipper_config.py` | Static check of both config folders ([testing](testing.md)) |
| `docs/Kalibrierung-Calibration.md` | User guide for macros and calibration (DE+EN) |
| `wiki/` | This wiki |

## The two config variants

The folders are **identical except for `printer.cfg` and `t5uid1.cfg`**. Expected differences:

- `SV04-with-display/printer.cfg`: `[include t5uid1.cfg]`
- `Sv04-works-with origin-klipper/printer.cfg`: stub macros `DGUS_PRINT_START/END`
- Deceleration limit is deliberately not set in either variant ([pitfalls](klipper-jinja-pitfalls.md)).

Check: `diff -r config/SV04-with-display "config/Sv04-works-with origin-klipper"` or
`python3 tools/check_klipper_config.py`.
